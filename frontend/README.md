# NutriSwap (Foodoscope)

Optional: copy React Bits files (JSX + CSS, same names) into `src/components/` to unlock the fancy visuals:
PixelBlast, TechText, SpecularButton, CursorGrid, InfiniteSpiral.

    npm install
    npm run dev

Mock data lives in `src/data.js`. Replace it with RecipeDB / FlavorDB calls.
